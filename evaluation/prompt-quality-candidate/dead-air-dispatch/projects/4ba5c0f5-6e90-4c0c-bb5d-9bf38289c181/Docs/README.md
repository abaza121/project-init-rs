# Dead Air Dispatch — Project Initiation Package

This directory is a planning baseline candidate for the first playable. It separates stakeholder authority, external evidence, and design inference so unresolved choices remain visible.

## Start here

- [Requirements.md](Requirements.md) — canonical verbatim brief clauses, generated requirements, acceptance criteria, and verification catalog.
- [Traceability.md](Traceability.md) — canonical constraints, consequential decisions, and exact trace edges.
- [OpenQuestions.md](OpenQuestions.md) — canonical unresolved choices and blockers.
- [Assumptions.md](Assumptions.md) — canonical non-authoritative inferences.
- [ValidationReport.md](ValidationReport.md) — checks actually performed on this package and their limits.

## Direction and identity

- [MissionVision.md](MissionVision.md) — proposed, non-authoritative mission and vision.

- [SWOT.md](SWOT.md) — initiation-stage strengths, weaknesses, opportunities, and threats, each labeled by provenance.

## Reading rules

- Requirement authority lives only in [Requirements.md](Requirements.md).
- Decision status lives only in [Traceability.md](Traceability.md).
- An item labeled **proposed**, **inference**, **recommendation**, **open**, or **unapproved** is not a stakeholder commitment.
- Research evidence constrains reasoning but never supplies project authority.
