# Interaction Inquiry

## Scope

This inquiry retains only material that shaped separable prototype experiments or the treatment of randomness. It does not turn accessibility guidance or design literature into stakeholder approval.

## Findings

EVD-002: W3C’s keyboard criterion states that content functionality is operable through a keyboard interface and explains that pointer actions should have a keyboard equivalent ([W3C WAI](https://www.w3.org/WAI/WCAG22/Understanding/keyboard.html)) supports DEC-006 because keyboard-operable functionality directly informs the proposed keyboard primary-action experiment.
EVD-003: W3C guidance says mouse, touch, keyboard, and speech input methods should be supported concurrently where devices offer several input methods ([W3C WAI](https://www.w3.org/WAI/WCAG22/Understanding/input-modalities.html)) supports DEC-007 because concurrent input methods directly inform the proposed pointer-and-touch primary-action experiment.
EVD-004: The PCG textbook states that generator evaluation should match the intended goal, with player-inclusive methods appropriate for engagement claims and goal-reflecting dimensions appropriate for variety ([Procedural Content Generation in Games, chapter 12](https://www.pcgbook.com/chapter12.pdf)) supports DEC-009 because goal-specific variation evaluation justifies isolating seeded variation until randomness goals are approved.

## Interpretation

Keyboard, pointer, and touch are separate experiments, not a bundled accessibility commitment. Likewise, deterministic content is a reversible prototype boundary, not a claim that randomness is undesirable. Hold alternatives, remapping, target size, cancellation, cues for disabled players, and all numeric variation settings remain outside approved scope.
