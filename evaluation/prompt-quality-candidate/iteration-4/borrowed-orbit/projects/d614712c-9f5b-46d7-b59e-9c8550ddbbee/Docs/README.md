# Borrowed Orbit

Borrowed Orbit is in planning. This package initiates a one-screen browser prototype for testing whether deliberate gravity-anchor switching can create learnable, predictable movement in runs shorter than three minutes. It preserves unresolved authority boundaries rather than treating recommendations as approvals.

## Authority model

The user brief controls product intent. Supplied answers preserve their stated authority boundaries. Working hypotheses and proposed choices are reversible until approved. External material can constrain a method but cannot select the audience, accessibility scope, randomness amount, low-end device cohort, or final physics model.

## Prototype boundary

The first build is a single-run, single-screen movement sandbox plus scoring and feedback sufficient to test the stated proof. Commercial positioning, monetization, accounts, persistence, social features, deployment, and unsupported technology choices are outside this initiation scope.
