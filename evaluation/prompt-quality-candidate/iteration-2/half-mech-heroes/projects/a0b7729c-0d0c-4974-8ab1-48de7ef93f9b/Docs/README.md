# Half-Mech Heroes — Project Initiation Package

This package establishes a prototype-ready foundation while preserving stakeholder authority over unresolved choices. The brief is canonical for product intent. Imported failed answers are recorded as non-resolutions, external claims are retained once as identified records, and provisional engineering thresholds are visibly marked as assumptions.

## Start here

- [Requirements.md](Requirements.md) is the canonical product register, including exact brief wording, acceptance criteria, and constraints.
- [OpenQuestions.md](OpenQuestions.md) is the canonical unresolved-choice register and records the eight supplied failed answers.
- [Assumptions.md](Assumptions.md) is the canonical inference register.
- [TechnicalArchitecture.md](TechnicalArchitecture.md) defines the provisional system shape and consequential decisions.
- [Traceability.md](Traceability.md) maps requirements to tests, decisions, constraints, assumptions, and retained external material.
- [ValidationReport.md](ValidationReport.md) records the static checks actually performed.

## Product direction

- [MissionVision.md](MissionVision.md) states the mission, vision, and prototype promise.
- [SWOT.md](SWOT.md) frames internal strengths and weaknesses and external opportunities and threats.
- [VisualIdentity.md](VisualIdentity.md) defines shape, colour, motion, readability, and interface character.
- [BrandPrompt.md](BrandPrompt.md) provides a reusable creative-generation prompt with explicit exclusions.

## Context files

- [Research-01-Audience.md](Research-01-Audience.md) covers audience and age-authority boundaries.
- [Research-02-Experience.md](Research-02-Experience.md) covers input, difficulty, and objective clarity.
- [Research-03-Market.md](Research-03-Market.md) records the deliberately limited market context.
- [Research-04-Technology.md](Research-04-Technology.md) covers controller abstraction.
- [Research-05-Delivery.md](Research-05-Delivery.md) covers platform-dependent release planning.
- [log-2026-08-30-09-24-40.md](log-2026-08-30-09-24-40.md) records the actual initiation session.

## Authority boundary

No document selects a primary platform, exact target age, hazard trio, success rule, multiplier formula, solo scope, remapping scope, or difficulty model. Work depending on those choices is designed behind explicit boundaries or remains blocked. External material is advisory and cannot substitute for a stakeholder answer.
