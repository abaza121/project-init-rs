# Working Inferences

## Assumptions
ASM-001: ASSUMPTION: A platform-neutral core and replaceable device adapters are a provisional engineering approach while the primary target platform remains unresolved; this is non-authoritative and must not be treated as stakeholder platform selection.
ASM-002: ASSUMPTION: "quick restarts" provisionally means no more than 5.0 seconds from restart input to regained control on reference hardware; this non-authoritative threshold requires stakeholder or playtest confirmation.
ASM-003: ASSUMPTION: Television readability will be provisionally tested on a 40-inch 1920×1080 display viewed from 3 metres in typical indoor light; this non-authoritative setup requires audience and platform confirmation.
ASM-004: ASSUMPTION: Exaggerated-physics scales and mechanical-failure timing will be tunable data values approved through playtesting rather than fixed in this package; this is a non-authoritative implementation inference.
ASM-005: ASSUMPTION: Five dyads with a four-of-five threshold are sufficient for prototype discovery of coordination mastery and comedy, not for population-level validation; this non-authoritative evaluation plan requires producer approval.
ASM-006: ASSUMPTION: "one city block" means one continuous playable level instance, not multiple blocks presented as one mission; this non-authoritative interpretation requires stakeholder confirmation if content structure changes.
ASM-007: ASSUMPTION: A shared keyboard will use two non-overlapping key groups routed to the same action domains as two controllers; exact keys are non-authoritative and remain a tuning choice pending OQ-001.
ASM-008: ASSUMPTION: A standard wreckage throw of two mech-heights plus a 15-degree damage recoil recovering within 0.8 seconds are provisional exaggerated-physics markers for prototype acceptance; these non-authoritative values require playtest confirmation.
