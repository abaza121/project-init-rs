# Generation Brief

Use the following prompt for provisional concept exploration only. It applies `REQ-013`, `ASM-008`, and `ASM-009`; it does not create a new approved visual choice.

## Prompt

Design a single-screen browser-game key frame for “Borrowed Orbit.” Show a tiny diamond-shaped satellite releasing from a circular moving planet into a clean curved arc while polygonal debris drifts inward toward a dense collapsing star. Include a few paired-chevron data fragments, one angular hazard with a near-miss glow, and an abstract orbit-multiplier ring. Use sparse geometric vector forms, generous negative space, crisp high-contrast silhouettes, restrained trails that explain momentum, and a solo-developer-feasible asset vocabulary. Provisional colors: deep navy background, warm-white satellite, cyan gravity connection and data, amber reward feedback, red-orange hazard and star pressure. No characters, no cockpit, no photorealism, no nebula texture, no dense star field, no explanatory copy, no logo lockup, no faux-3D, no ornate UI, and no imagery that implies a selected physics formula. Compose for one fixed landscape viewport with the satellite and its next anchor immediately legible.

## Evaluation lens

Accept a concept only when the attachment target, release arc, inward danger, collectible, and hazard skim can be distinguished without explanatory text; the shapes remain reproducible from primitives; and the composition does not imply features beyond `REQ-001` through `REQ-015`.
