[SDKs and system requirements — Apple Developer](https://developer.apple.com/xcode/system-requirements/) supports DEC-006 because Xcode host requirements constrain build feasibility without selecting Pigeon Payroll’s primary mobile platform.

[Install Android Studio — Android Developers](https://developer.android.com/studio/install) supports DEC-006 because Android tooling host availability constrains feasibility without selecting Pigeon Payroll’s primary mobile platform.
EVD-016: Google documents that Android applications encounter device configurations that vary by hardware features, screen configuration, and platform version and provides compatibility controls for those differences. [Device compatibility overview — Android Developers](https://developer.android.com/guide/practices/compatibility) supports DEC-006 because Android device variability affects testing effort without selecting Pigeon Payroll’s primary mobile platform.
