# Delivery Notes

## Evidence
EVD-014: GOV.UK guidance says success measures should show how well a product solves its intended problem and should evolve as understanding of user needs develops ([Define what success looks like and publish performance data](https://www.gov.uk/service-manual/service-standard/point-10-define-success-publish-performance-data), accessed 2026-08-30). EVD-014 supports DEC-017 because intended outcomes must be chosen before Last Light Courier can adopt continuation measures.
EVD-015: GOV.UK guidance says usability-test tasks and success criteria should reflect the product’s development stage and the prototype should suit the question being investigated ([Usability testing: qualitative studies](https://www.gov.uk/guidance/usability-testing-qualitative-studies), accessed 2026-08-30). EVD-015 supports DEC-017 because prototype verification cannot be relabeled as stakeholder-approved continuation success criteria.

## Stage Boundary

The present stage is initiation. This package defines build-level acceptance observations but does not claim product viability, usability, retention, market fit, or continuation readiness. That distinction applies EVD-014 and EVD-015 without granting them stakeholder authority.

## Build Gate

A candidate prototype revision is internally testable only when every gameplay acceptance record has a recorded observation, the two artifacts in AC-002 launch from the same revision, open choices are labeled, and failures remain visible. Passing that gate is not a continuation decision; DEC-017 and OQ-005 control that boundary.
