# Player Experience Notes

## Evidence
EVD-001: Experienced game difficulty depends on the balance between a player’s abilities and the barriers presented by the game ([Xbox Accessibility Guideline 108](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/108), accessed 2026-08-30). EVD-001 supports DEC-013 because player-dependent difficulty does not establish Last Light Courier’s desired default challenge.
EVD-002: Microsoft advises consulting user-research partners and the Gaming & Disability Community to identify suitable difficulty options for a specific game ([Xbox Accessibility Guideline 108](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/108), accessed 2026-08-30). EVD-002 supports DEC-013 because project-specific difficulty consultation supports deferral rather than an evidence-invented default.
EVD-003: IGDA accessibility guidance advises designers to decide how they want players to feel while recognizing that difficulty is relative ([IGDA Game Accessibility SIG Top Ten](https://igda-gasig.org/how/sig-top-ten/), accessed 2026-08-30). EVD-003 supports DEC-013 because the intended player feeling remains a designer or stakeholder choice.
EVD-004: Microsoft recommends that keyboard-supported games make required interface and gameplay controls available through keyboard-compatible digital input, allow in-game remapping, and update displayed prompts after remapping ([Xbox Accessibility Guideline 107](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/107), accessed 2026-08-30). EVD-004 supports DEC-014 because keyboard operation, remapping, and prompt behavior are separable accessibility-scope choices rather than one authorized bundle.
EVD-005: Microsoft recommends presenting gameplay-critical visual and audio information through additional sensory methods and supplementing critical color coding with shapes, patterns, icons, or text ([Xbox Accessibility Guideline 103](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/103), accessed 2026-08-30). EVD-005 supports DEC-014 because redundant cues and non-color identifiers require a separable presentation seam while accessibility scope remains unresolved.
EVD-006: Microsoft recommends independent adjustment or muting of audio categories such as music, active gameplay effects, and ambient effects ([Xbox Accessibility Guideline 105](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/105), accessed 2026-08-30). EVD-006 supports DEC-014 because independent audio categories are a distinct accessibility-scope choice.
EVD-007: Microsoft recommends configurable contrast and identifies contrast thresholds of 4.5:1 for important standard-size text and visual elements and 3:1 for large-scale elements ([Xbox Accessibility Guideline 102](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/102), accessed 2026-08-30). EVD-007 supports DEC-014 because contrast configuration and thresholds are distinct practices whose prototype priority remains unapproved.
EVD-008: Microsoft recommends allowing game text and associated icons or glyphs to scale to 200% without losing content, functionality, or meaning ([Xbox Accessibility Guideline 101](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/101), accessed 2026-08-30). EVD-008 supports DEC-014 because text scaling is a distinct accessibility-scope choice rather than stakeholder authority for a bundled package.
EVD-009: Microsoft recommends disabling nonessential moving, blinking, scrolling, or flashing content and testing games for photosensitive seizure triggers, preferring removal of hazardous content over warnings ([Xbox Accessibility Guideline 118](https://learn.microsoft.com/en-us/xbox/accessibility/xbox-accessibility-guidelines/118), accessed 2026-08-30). EVD-009 supports DEC-014 because reduced-effects controls and photosensitivity testing are distinct scope choices requiring explicit prioritization.
EVD-010: The MDA framework defines aesthetics as desirable emotional responses, describes mechanics as producing dynamics that lead to those responses, and advocates experience-driven design ([MDA: A Formal Approach to Game Design and Game Research](https://www.cs.northwestern.edu/~hunicke/MDA.pdf), accessed 2026-08-30). EVD-010 supports DEC-015 because progression mechanics should follow an intended long-term player experience rather than precede it.
EVD-011: A peer-reviewed motivational model proposes competence, autonomy, and relatedness as distinct contributors to video-game appeal and sustained engagement ([A Motivational Model of Video Game Engagement](https://selfdeterminationtheory.org/SDT/documents/2010_PrzybylskiRigbyRyan_ROGP.pdf), accessed 2026-08-30). EVD-011 supports DEC-015 because multiple motivational dimensions do not select one progression model for Last Light Courier.

## Boundary

These sources provide design considerations, not project authority. The inference applied here is limited: make relevant systems configurable and keep stakeholder-owned experience choices open. OQ-001, OQ-002, and OQ-003 remain unresolved.
