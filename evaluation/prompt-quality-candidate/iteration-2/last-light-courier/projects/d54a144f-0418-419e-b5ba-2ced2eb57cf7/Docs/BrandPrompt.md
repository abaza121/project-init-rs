# Concept Prompt

## Purpose

Use this prompt to explore a reversible key visual, title treatment, or in-game style frame. It is constrained by REQ-003, REQ-004, REQ-005, REQ-006, REQ-007, REQ-014, REQ-015, DEC-006, and DEC-010. It is not approval of final art, an audience claim, or an accessibility decision.

## Main Prompt

Create a crisp 2D arcade-game style frame for **Last Light Courier**. Show one tiny white arrowhead courier ship crossing a single fixed top-down city playfield during a total blackout. Behind the ship, draw one continuous electric-cyan route: a bright narrow core with restrained glow, visibly powering small geometric city blocks while also forming hard maze walls that close off the ship’s future path. Include one small magenta parcel token with a bold triangle glyph and one matching outlined tower beacon repeating the same magenta color and triangle glyph. Show a tight near-pass between the ship and an older solid trail segment to communicate precision. Keep the composition fast, uncluttered, geometric, high contrast, and readable at thumbnail size. Use flat vector shapes, sparse squared typography, stable HUD indicators for battery, score, and multiplier, and a nearly black navy field. The emotional tone is urgent, elegant, lonely, and electrically hopeful. Emphasize that the route itself is the city’s last light and the player’s self-built obstacle.

## Negative Prompt

No detailed painted art, no 3D perspective, no side-scrolling camera, no character portraits, no photorealism, no texture-heavy buildings, no giant spaceship, no combat weapons, no explosions dominating the frame, no multiple overlapping HUD panels, no illegible tiny text, no color-only parcel matching, no uncontrolled bloom, no rapid-flash motif, no cyberpunk crowd scene, and no visual element implying persistent upgrades or a campaign.

## Output Notes

- Aspect ratio: 16:9 for a style frame; preserve a centered safe area for a square crop.
- Priority order: ship, route, old-trail danger, parcel-to-tower match, powered city, HUD.
- Keep glow outside collision cores so the playable geometry remains inspectable.
- Treat palette values in [VisualIdentity.md](VisualIdentity.md) as provisional exploration values.
- Any generated concept must be checked against CON-002, CON-004, and AC-014 before use.
