# Last Light Courier Project Foundation

This package initiates the prototype without pretending that unresolved stakeholder choices have been answered. The exact brief is preserved in the canonical product contract, and externally attributable claims appear only as `EVD-*` records in the topic notes.

## Start Here

1. Read [Requirements.md](Requirements.md) for the exact brief, supplied answers, canonical `REQ-*` records, and objective `AC-*` checks.
2. Read [OpenQuestions.md](OpenQuestions.md) before adopting difficulty, accessibility, progression, audience, continuation, compatibility, collision, or tuning values.
3. Read [TechnicalArchitecture.md](TechnicalArchitecture.md) for the canonical `DEC-*` records and provisional implementation shape.
4. Use [Traceability.md](Traceability.md) to inspect exact requirement-to-acceptance and requirement-to-decision coverage.
5. Read [ValidationReport.md](ValidationReport.md) for checks actually performed on this package.

## Authority Boundary

The brief and supplied `ANS-*` records are project inputs. `ASM-*` records are non-authoritative inferences. `EVD-*` records can constrain a choice but cannot make a stakeholder choice. A `DEC-*` record marked `Deferred` is not an adopted design value.
