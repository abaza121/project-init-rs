# Generative Art Brief

## Status

This prompt operationalizes the provisional identity in DEC-023, DEC-024, DEC-025, and DEC-026. Generated work is concept exploration only and must not be treated as final art, a platform asset, or an accessibility solution.

## Primary Prompt

Create a restrained key-art and identity exploration for “Dead Air Dispatch,” a strange 2D PC score-attack game about operating an emergency radio during a supernatural storm. Show one isolated radio station room as a near-black silhouette, an oversized circular tuning dial, a broken carrier waveform crossing the composition, faint safe-route geometry appearing only inside selected frequency bands, distant caller beacons, and hostile interference curling toward an antenna. Visual language: civil-defence instrument panel, oscilloscope traces, abstract waveforms, controlled analogue static, sharp silhouettes, sparse screen-print texture, tense negative space. Palette: storm black, receiver bone, carrier cyan, warning amber, restrained interference magenta. Typography area reserved for a narrow uppercase title and compact monospaced frequency readout. Mood: procedural, lonely, uncanny, urgent, legible. Strong hierarchy, minimal clutter, flat 2D shapes, no photorealism, no glossy 3D rendering, no character portrait, no generic lightning-bolt logo, no excessive VHS nostalgia, no illegible pseudo-text, no colour-only gameplay diagram.

## Mark Prompt

Design a simple one-colour vector mark: circular radio tuning dial, one broken horizontal carrier waveform, one small off-centre caller beacon, strong silhouette, recognizable at 32 px, balanced negative space, no letters, no gradients, no skull, no lightning bolt.

## Evaluation

Concept review should check visual connection to the radio, storm, waveform, caller, and interference subjects in REQ-001 and REQ-008; consistency with the four provisional identity DEC records; legibility as a silhouette; and absence of unintended final-scope or accessibility claims. Stakeholder approval is still required before adoption.
