## Record Policy

Canonical records appear once in their owning files. Other documents reference their identifiers instead of restating externally attributable claims. Proposed identity and technical treatments remain provisional where their DEC provenance says inference. Each open question blocks only the choice it names; none erases the playable loop authorized by the brief-derived product records.
