# Brand exploration prompt

Status: reusable creative prompt derived from R-013, R-014, R-015, R-016, and [VisualIdentity.md](VisualIdentity.md). It may generate concepts, not requirements or approved brand assets.

## Primary prompt

> Create a single-screen visual concept for **Borrowed Orbit**, a minimalist one-button browser game. Show a very small geometric satellite releasing from a nearby circular gravity anchor while preserving tangent momentum into a clean new arc. Other circular planets and angular debris move inward toward a compact collapsing star. Include open-square data fragments, one angular hazard with a clearly different skim halo, a restrained orbit-multiplier ring, and a thin active-anchor tether. Use sparse geometric space art, abundant negative space, crisp flat shapes, and short trajectory echoes. The composition must make attach, release, momentum, nearest-anchor choice, danger, and inward pressure readable through shape and motion cues rather than instructional text. Keep the asset language plausible for one solo developer using vector primitives and procedural effects. Proposed palette: near-black `#080B14`, satellite white `#F3F7FF`, gravity cyan `#67D9FF`, data green `#A8FFB0`, hazard red `#FF6B78`, skim amber `#FFCA68`, collapse violet `#C76BFF`. Color is secondary to shape. Landscape browser-game frame, no scene cuts, no realistic space rendering.

## Negative prompt

> No photoreal planets, detailed spaceship illustration, dense star field, cinematic cockpit, multiple screens, menus covering play, text instructions, dialogue, characters, logos copied from existing games, gradients that obscure collision boundaries, color-only state communication, motion blur that hides trajectories, or assets requiring a large art team.

## Review checklist

A concept is retained only if it:

- supports the one-screen reading in R-016;
- represents the core states in the R-012 cue matrix without instructional copy;
- uses geometric/procedural recipes consistent with R-013 and R-014;
- clearly separates collision, skim, collectible, anchor, and player shapes;
- does not imply unapproved physics, tuning, audience, accessibility mode, performance, or randomness choices.

Generated imagery must be treated as exploratory. T-013 and T-014 apply only after an asset is selected and documented.
